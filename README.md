# 2026-6302-4
# Назначение и суть проекта
Вк-бот "NewsAgent", который собирает новости с различных источников по заданной теме, пересказывает в указанные день и время их короткими тезисами в выбранном пользователем стиле и даёт ссылку на полный источник в случае заинтересованности пользователя. Агент работает автономно: раз в час проверяет источники, фильтрует мусор и неподходящие под тему новости, сокращает текст через нейросеть без лишних деталей и отдаёт готовую подборку. Также предусмотрена возможность общения с пользователем, чтобы тот мог уточнять различные аспекты и получать достоверную информацию, подкрепленную реальными фактами из интернета.
# Как запустить проект

# Требования:
- Python 3.10 или выше
- Установленный pip
- Токен доступа VK API для сообщества
- API-ключ для нейросети (для AI-функций)

# Установка и запуск:
1. Клонируйте репозиторий:
git clone https://github.com/algorithm-ssau/2026-6302-4.git
cd 2026-6302-4
2. Установите зависимости:
pip install -r requirements.txt
3. Создайте файл .env в корне проекта и добавьте токен VK-сообщества:
VK_TOKEN=ваш_токен_сообщества
4. Запустите бота:
python vk_bot.py
5. Напишите боту в личные сообщения сообщества: /start или просто "Привет"

# Примечания:

Бот не может написать пользователю первым - нужно начать диалог.
Для работы AI-функций (умный пересказ и ответы на вопросы) требуется дополнительный API-ключ (OpenAI, GigaChat или YandexGPT).

# Архитектура решения

Проект построен по модульному принципу и состоит из следующих компонентов:
1. Парсеры (папка parser/)
- rss_parser.py - сбор новостей из RSS-лент через feedparser;
- html_parser.py - парсинг обычных веб-страниц через BeautifulSoup;
- sources.py - мультипарсер, автоматически определяющий тип источника (RSS или HTML).
2. Фильтрация (filter.py)
- Фильтр по ключевым словам - оставляет новости с заданными словами;
- Контекстный фильтр - на основе TF-IDF и косинусного сходства;
- Кэширование отправленных новостей для исключения дубликатов.
3. Агент (agent.py) — главный пайплайн обработки:  
- Парсинг;
- Нормализация;
- Фильтрация;
- Дедупликация;
- Ограничение; 
- Форматирование;
- Вывод.
4. VK-бот (vk_bot.py)
- Интерфейс для пользователя: кнопки, команды, диалог;
- Сохранение настроек пользователя (тема, стиль);
- Обработка команд: "Новости", "Настройки", "Помощь".
5. Конфигурация (config.py) — все настройки: ключевые слова по темам, пороги фильтрации, стили пересказа, лимиты.
6. Нейросетевой и экстрактивный пересказ (summarizer.py)
7. Вопросно-ответный агент с веб-поиском (qa_agent.py)
